So funktioniert es
  1. Server einmalig mit Admin-Token starten (siehe Status-Box oben).
  2. Genau dieses Token unten eintragen — es muss identisch sein.
  3. Auf „Login-Code erzeugen“ klicken → 15-stelligen Code an den Kunden geben.
  4. Optional pro Ziel einen 20-stelligen Freigabecode erzeugen.
1 · Admin-Token
2 · Kunden-Login-Code (15 Zeichen, wiederverwendbar)
Damit loggt sich ein Kunde ein (Feld „Login-Code“ im Engagement-Dialog).

  


  

    
3 · Freigabecode für ein Ziel (20 Zeichen, einmalig)

    
Zusätzlich nötig, damit ein Kunde genau dieses eine Ziel prüfen darf.
